# FabVEX DuckDNS updater

Install-FabVex-DuckDNS-Task.ps1 keeps the selected DuckDNS hostname synchronized with the server's current public IP.

## Install

Run from an elevated PowerShell prompt:

    powershell -ExecutionPolicy Bypass -File .\Install-FabVex-DuckDNS-Task.ps1

The installer automatically looks for the private server.env generated by the FabOS CLI. It runs as SYSTEM every 10 minutes by default and performs an immediate first update.

## Remove

    powershell -ExecutionPolicy Bypass -File .\Install-FabVex-DuckDNS-Task.ps1 -Remove

The updater never prints the DuckDNS token. Keep server.env private and do not expose port 8000.
