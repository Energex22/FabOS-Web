# FabVex FabOS API service reference
#
# The supported Windows installer creates the service directly with sc.exe;
# this file documents the equivalent process entry point for manual service
# wrappers.
#
# Application:
#   C:\FabVex\FabOS\.venv\Scripts\python.exe
# Arguments:
#   deployment\windows\run_api_service.py --host 127.0.0.1 --port 8000 --threads 8 --data-dir C:\FabVex\Data --env-file C:\FabVex\FabOS-Web\deployment\windows\server.env
# Startup directory:
#   C:\FabVex\FabOS
#
# The entry point loads the private environment and starts the current FastAPI
# application with one Uvicorn worker. Keep the API bound to 127.0.0.1; Caddy
# is the only public entry point.
#
# Do not use the legacy fabos_api.server WSGI entry point for the storefront
# production service because the current FastAPI surface contains the complete
# customer upload, checkout, and administrator route set.
